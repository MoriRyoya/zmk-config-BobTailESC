# BobTailBar — macOS メニューバー常駐アプリ

CodexBar と同じく、**設定からメニューバーに出す項目を選べます**。レイヤー表示・左右バッテリー・キーマップ確認・ジェスチャの感度もここから変えます。

---

## インストール

```bash
cd tools/macos/BobTailBar
./build.sh install
```

起動後、**システム設定 → プライバシーとセキュリティ** で次を許可し、アプリを再起動してください。

| 項目 | 用途 |
| --- | --- |
| アクセシビリティ | レイヤー通知の受信とジェスチャ変換 |
| Bluetooth | 左右のバッテリー残量 |

---

## メニュー

クリックすると次が出ます。

| 項目 | 内容 |
| --- | --- |
| キーマップオーバーレイ ⌘K | 現在レイヤーの配列を半透明で重ねる（オン / オフ） |
| 設定… ⌘, | 表示・キーボード・キーマップ・ジェスチャ・一般 |
| トラックボールジェスチャ | 一時的にオン / オフ |
| バッテリーを再取得 | BLE を読み直す |

---

## 設定

### メニューバー

チェックで表示 / 非表示、上へ / 下へで順番です。

- レイヤー（ABC / 123 / SYM / GES / FN / SCR / WIN）
- OS モード（mac / win）
- 左バッテリー %
- 右バッテリー %
- 少ない方のバッテリー %
- ジェスチャ状態

区切り文字と L/R プレフィックス、文字サイズも変えられます。プレビューが上部に出ます。

### キーボード

- **キーボードに追従** … Fn 層の Mac / Win キー（F19 / F20）に合わせる
- **macOS 表示に固定** / **Windows 表示に固定** … キーマップ確認とバッジだけアプリ側で切り替える

本体の Win 層そのものは ZMK 側のキーで切り替わります。アプリから HID でファームウェアのレイヤーを書き換えることはできません。

### キーマップ

設定ウィンドウの「キーマップ」タブに、**いま押しているレイヤー**の配列が出ます。レイヤーを持ち替えると表示が追従します。

作業しながら見るときは、同じタブの **作業画面に半透明で重ねる** をオンにするか、メニューの「キーマップオーバーレイ」を使います。

- 透明度はスライダーで 25%〜100%
- クリック透過をオンにすると、重ねたまま他のアプリを操作できます
- 「ベースレイヤーでは隠す」と、四隅への配置も選べます

### ジェスチャ

オン / オフ、フルスワイプに必要な移動量（小さいほど敏感）、Windows 時だけ使う連打間隔。
macOS では純正トラックパッドの 3/4 本指スワイプと同じ経路で、ボールの動きに追従します。

### 一般

ログイン時起動。

---

## キーマップ

設定の「キーマップ」タブと、半透明オーバーレイのどちらも、押しているレイヤーに追従します。Windows 表示に固定しているときは括弧まわりなどの Win 差分も切り替わります。

---

## レイヤー通知（ファームウェア側）

| キー | 意味 |
| --- | --- |
| F13 | Num+Nav |
| F15 | Sym |
| F16 | Scroll |
| F17 | Gesture |
| F18 | Fn |
| F19 | macOS モード |
| F20 | Windows モード |

不要なら `config/BobTail.keymap` の `#define LAYER_INDICATOR 1` を `0` にします。
